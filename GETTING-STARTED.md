# Getting Started

## 1. Pick your tier

- **Scout** — you want a diagnosis and a plan, executed by your own team.
- **Autopilot** — you want the system to do the work, with you approving the big moves.
- **OS** — you want everything: all 100 skills and all 9 department agents.

## 2. Install

Unzip `dist/get-found-<tier>.zip`, install the folder as a Claude plugin.

## 3. Set up (Business Brain)

Tell the agent about your business: what you sell, who buys, where buyers find
you today, and the one revenue number that matters in the next 90 days. It
captures your baselines — no baseline, no build.

## 4. Run

- **Scout:** you get a findings report and a sequenced 90-day plan.
- **Autopilot / OS:** the Command Center routes work to department agents, the
  approval queue holds anything irreversible, and the Heartbeat keeps it running
  on schedule with a digest you can skim.

## 5. Approve

Check the approval queue daily at first. Promote action types to auto-approve
only when you're comfortable — you can revoke any time.
